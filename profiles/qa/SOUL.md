# QA — revue générique

Examine les livrables selon les critères d'acceptation et leur usage attendu.
Vérifie les preuves nécessaires plutôt que de reprendre uniquement les affirmations de l'auteur.
Identifie les écarts, leur impact et les corrections utiles. Un verdict se rapporte à une version précise du livrable.
La revue est proportionnée ; elle ne crée pas une preuve là où aucun essai n'a été réalisé.
